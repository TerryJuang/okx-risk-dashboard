## 修改檔案

- `dist/index.html`：分組框、方向圖示、EXIT MAP 摘要／左右佈局、停損提示容器及折疊說明。
- `dist/style.css`：必要樣式，價格軸與標籤固定同高；小螢幕保留右側價格軸。
- `dist/app.js`：繪圖方向、價位旁提示按鈕、兩個摘要值與三位小數顯示。
- `dist/tooltips.js`：改事件委派，使每次計算重新產生的停損問號仍可 hover／focus；輸入更新時關閉舊提示。
- `tests/risk.test.cjs`：價格反算改讀垂直座標；增加顯示精度、摘要及提示同步／清空驗證。
- `tests/tooltips.test.cjs`：驗證動態按鈕 hover、focus、Escape 與輸入後關閉。
