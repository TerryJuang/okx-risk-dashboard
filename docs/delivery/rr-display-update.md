# RR 與顯示精度更新

2026-10-13（Asia/Taipei）

- 輸入標籤改為「盈虧比 RR」，移除「（價格）」。
- 多空 RR 參考門檻均為嚴格大於 1；1 本身不算大於 1。
- 移除右側 RR「符合／不符合」檢查；RR 與費用後 RR 不阻擋輸出記錄。正數 RR 即使不超過 1 仍可保存；強平距離、槓桿、有效價格、數字範圍與非零倉位限制保留。
- 試算結果、價格、金額、百分比、RR 與紀錄管理的金額／數量／比率統一四捨五入顯示兩位小數。輸入、內部計算、原始快照及匯出仍保留原精度，日期、週期及筆數維持原格式。
- Firestore 移除舊多空 RR 門檻，rrOk 欄位仍驗證 boolean；身分、核准名單、帳號隔離、欄位驗證及不可覆寫修訂保持原規則。
- 新快照記錄更新後的 calculator SHA-256；規則同時接受舊版本標記，保留既有紀錄相容性。

驗證新增 RR 0.5、1、1.000001、1.5036 的雙向邊界與正式保存程式／規則測試；既有固定基準仍比較所有財務數值，只排除本次授權變更的三項判定旗標，另外以邊界測試覆蓋新政策。
