## 3. 固定保留的計算與操作規則

令方向 s 為做多 +1、做空 −1；E 為入場價、C 為總資金、L 為槓桿、d 為停損距離小數，fo/fc 為開倉／平倉費率小數，a 為滑價小數，m 為維持保證金率小數。

| 項目 | 現行公式／行為 |
| --- | --- |
| 適用範圍 | 單一 USDT 本位線性永續逐倉；不接交易帳戶或即時行情 |
| 停損／停利 | SL = E × (1 − s×d)；TP = E × (1 + s×d×RR) |
| 假設成交價 | SLfill = E × (1 − s×(d+a))；TPfill = E × (1 + s×(d×RR−a)) |
| 預算 B | C × 風險百分比 ÷ 100；風險％與虧損金額以最後編輯欄位為準 |
| 損失率／獲利率 | lossRate = d+a+fo+fc×SLfill/E；profitRate = d×RR−a−fo−fc×TPfill/E |
| 原始目標倉位 | targetNotional = B ÷ lossRate |
| 保證金上限 cap | C × min(3, 切分份數) ÷ 切分份數；建議至少 10 份，少於 10 份警告 |
| 實際倉位 N | min(targetNotional, cap×L, C÷(1/L+fo))，以 0.01 U 向下取整 |
| 保證金／盈虧 | M=N/L；預估虧損=N×lossRate；預估獲利=N×profitRate |
| 資金需求 | 開倉費=N×fo；合計需 M+開倉費，開倉費不再從 M 重複扣除 |
| 強平估算 | E×(1−s/L)÷(1−s×(m+fc))；明確保留「估算」及假設限制 |
| 強平條件 | s×(E−強平價)/E，嚴格大於 d×(1+額外緩衝％/100)+a+1e−12 |
| RR | 做多價格 RR>2，做空≥1；費用後 RR=profitRate/lossRate，未達只警告 |
| 試算合格 | 價格 RR 合格、強平位置合格、不超過設定的合約槓桿上限、N>0 |
| 槓桿 | 可選整數 1–100 倍；不自動降低。另算符合假設的建議上限 |
| 方向切換 | 保留停損距離，重新推算另一方向的停損價格 |
| 預設 | 入場與停損價格空白；做多、停損 2%、RR 3、總資金 500、風險 2%、虧損 10、槓桿 20、切分 10 |
| 精度 | 計算以現有 JS number；輸入同步 12 位有效數字；倉位向下取整至 0.01；保證金顯示兩位並維持淺藍色 |
| 空值／無效值 | 空值清除結果並顯示待輸入；無效條件顯示原警告；不得沿用過期輸出 |
| 說明與收合 | 6 個問號移入即顯示、無需點擊，保留鍵盤 focus；備註小字斜體；資金切分預設收合；原有資訊揭露保留 |

所有現有輸入上下界、價格正值檢查、倉位過大檢查與浮點容差都保持不變。

特別需要理解的既有行為：

1. 槓桿改變只有在資金切分／可用資金上限未限制倉位時，才保持名目倉位固定。
2. 做空價格 RR=1 可顯示試算條件符合，同時出現費用後 RR 未達 1 的警告。這是目前已測試的規則，不在 UI 任務中變更。
3. 做多 1 倍的模型強平價為 0；保留原有「不代表實際無風險」說明。
4. 現有 EXIT MAP 是按價格排序的等距清單，且已標明非等比例；它不是價格軸。

## 5. Dashboard 方案

- **視覺**：深石墨背景與分層卡片，保留 R 品牌、繁體中文、核心標語及萊姆綠識別；保證金淺藍、獲利綠、虧損橘紅，另以文字與符號辨識狀態。數字使用等寬數字，價格、金額與單位一致對齊。
- **桌面**：主區左側約 360px 交易參數，右側為結果與 EXIT MAP。主要結果摘要在足夠寬高時 sticky；不固定整張高卡片，避免警告或進階設定無法捲動。
- **平板**：依可用寬度調整為較緊湊雙欄或單欄，取消會壓縮操作區的固定效果。
- **手機**：垂直卡片依序為交易參數、結果、EXIT MAP、資金分配及計算說明；不使用遮擋輸入的固定浮層。長標籤可換行，輸入與滑桿維持可操作大小。
- **參數**：價格與停損、RR、總資金與單筆風險分組。強平／交易成本仍可收合；停損與風險兩組雙向連動、最後編輯優先完全保留。
- **結果**：名目倉位、保證金、停損虧損、停利獲利、價格／淨 RR、估算強平價集中；顯示既有條件檢查及槓桿／資金警告。
- **EXIT MAP**：採原生 SVG 線性價格軸，4 個價位依數值比例定位；標記分別使用名稱、線型及顏色。多空依價格排序，自動切換損益方向；相近標記以引線及獨立數值清單避開重疊，不任意拉開點位。極端價差仍保留完整軸與清單，不隱藏估算強平價。
- **資金圖**：顯示「保證金／開倉費／其餘資金」比例，數據來自既有結果；停損虧損額作獨立風險標示，避免與保證金加總而重複計算。切分設定仍預設收合，並保留 3 份上限的文字／標記。
- **不增加行情功能**：不生成 K 線、不接 API、不增加下單功能。

主要相容性風險：既有腳本以 DOM ID 綁定；改排版時需保留全部 ID。提示採 fixed 定位，新祖先元素不要使用會改變 fixed 座標的 transform。長金額、1000 份切分、小價格、接近的標記可能造成擁擠，需列入視覺驗收。GitHub 專案頁有路徑前綴，保留目前相對資源網址，不引入根目錄絕對路徑。
